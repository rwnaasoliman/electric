# موقع كهرباء بلس

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `electricity_portfolio`.
3. افتح `index.html` باستخدام المتصفح أو إضافة Live Server في VS Code.

## قبل النشر
- افتح `script.js` وغيّر `WHATSAPP_NUMBER` إلى رقم صاحب الشغل بصيغة دولية بدون +، مثل `2010XXXXXXXX`.
- غيّر رقم الهاتف `01012345678` في `index.html` إلى رقم صاحب الشغل، وكذلك روابط الاتصال.
- عدّل الاسم "كهرباء بلس" والمناطق والخدمات حسب النشاط الفعلي.
- استبدل صور معرض الأعمال بصور حقيقية للمشروعات. الصور الحالية روابط إنترنت، لذا تحتاج اتصالًا بالإنترنت للعرض.
- الموقع واجهة أمامية؛ نموذج التواصل يجهّز رسالة واتساب ولا يخزن البيانات في قاعدة بيانات.

## الملفات
- `index.html`: هيكل الموقع العربي.
- `style.css`: التصميم المتجاوب.
- `script.js`: قائمة الموبايل وروابط واتساب ونموذج الطلب.
